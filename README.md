A. Bash Learning:
A step-by-step collection of Bash scripting tutorials and practice exercises for beginners. This repository documents my learning journey, with each script focusing on a specific Bash concept.

B. Topics Covered:
Variables (System & User-Defined)
User Input (read, -p, -s, -a)
Command-Line Arguments ($0, $1, $@, $#)
Arrays
Practice Programs

C. Repository Structure
01-variables.sh
02-user-input.sh
03-command-line-arguments.sh
and so on.

Each file introduces a new concept with examples and practice code, making it easy to learn Bash scripting step by step.

D. Goal
This repository serves as a personal learning resource while building a strong foundation in Linux Bash scripting. New topics and mini-projects will be added as I continue learning.
